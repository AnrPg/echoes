## Versions in an export

Settings on the export page:

- **Versions**: only the one shown in ChatGPT (default), or all versions.
- **Other versions go**: in the same file (shared turns once, then `## Branch k of n: name` sections) or in one file
  each (`<title> (branch k).md`). JSON always holds the whole tree.

A chat that has versions also gets a `## Conversation tree` Mermaid diagram and `<title>.tree.json` (format
`echoes-tree` v1: nodes depth-first with a short preview, `k/n` version positions and the active path). Chats without
versions get neither.

Branch names come from the forks along the path, e.g. `Turn 2 edited (v2) to Turn 5 regenerated (v1)`.

## HTML and PDF

- **HTML** is a format on the export page, for single and bulk export. Each chat is one self-contained page: CSS
  inline, math as MathML (rendered natively by the browser, so no math fonts or scripts), code highlighted with
  Shiki, no scripts at all (a Content-Security-Policy in the page blocks them). Raw HTML inside a chat is shown as
  text. Images and files are linked from the `<title>_files/` folder, as in Markdown.
- **Look** (theme): Like ChatGPT, Article, Compact notes, Print-friendly. Each follows the reader's light or dark
  setting; printing is always light.
- **Save as PDF** (on a single chat) renders the chat as HTML with images embedded and opens the browser's print
  dialog, where you choose "Save as PDF". The text stays vector and selectable.
- Print rules: long code wraps and may split across pages; code blocks up to 15 lines, notes, images and display
  math stay whole; tables shrink; reasoning summaries print open.

Decisions and limits:

- Math is MathML, not KaTeX's HTML+fonts output: files stay small and need no bundled fonts. Chrome, Edge, Firefox
  and Safari render MathML.
- Fonts are the system's, with fallbacks for Greek, Cyrillic, Hebrew, Arabic, CJK and emoji. Bundling fonts (the
  Build Plan item) is deferred: it would add megabytes to every file.
- Bulk PDF is not offered: printing many chats without a dialog needs the `debugger` permission, which shows a
  warning bar. Bulk HTML prints the same way, one file at a time.
- The Mermaid tree diagram is only in Markdown (HTML would need Mermaid's script); `tree.json` is written for both.
