## Versions in an export

Settings on the export page:

- **Versions**: only the one shown in ChatGPT (default), or all versions.
- **Other versions go**: in the same file (shared turns once, then `## Branch k of n: name` sections) or in one file
  each (`<title> (branch k).md`). JSON always holds the whole tree.

A chat that has versions also gets a `## Conversation tree` Mermaid diagram and `<title>.tree.json` (format
`echoes-tree` v1: nodes depth-first with a short preview, `k/n` version positions and the active path). Chats without
versions get neither.

Branch names come from the forks along the path, e.g. `Turn 2 edited (v2) to Turn 5 regenerated (v1)`.
