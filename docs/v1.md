# v1 core: status

v1 ships the export core: adapters, model, Markdown/JSON rendering and the extension's single-chat and bulk export.
Gate addition from the API-first decision: `@echoes/core` and the export adapter are published as 0.x with generated docs.

Phase 0's capture report has not arrived yet, so v1 is split by whether a step needs real ChatGPT response shapes.

## Not blocked (shape-independent)

| Step | Where | State |
| --- | --- | --- |
| pnpm workspace (`packages/*`, `apps/*`) | root | done |
| Normalized model, zod schemas, JSON Schema v1 | `packages/core/src/model/schema.ts`, `schemas/` | done |
| Validation with tree integrity | `model/validate.ts` | done |
| Tree: active path, traversals, version groups, path through a version | `model/tree.ts` | done |
| Turns and turn-definition presets | `model/turns.ts` | done |
| Scheduler with injected `Transport`, backoff, `Retry-After`, pause on 401/challenge | `packages/core/src/queue/` | done |
| `Store` and `OutputSink` ports, job checkpoints | core | next |
| Markdown renderer (tokenizer-based LaTeX, `$` escaping), JSON output | core | next |
| Search normalization (NFKC, case-fold, marks, σ/ς, CJK) | core | next |
| Official `conversations.json` adapter | `packages/adapter-chatgpt-export` | needs a real export sample (Settings → Data controls → Export) |

## Blocked on the Phase 0 report

- `adapter-chatgpt-api`: conversation endpoint, content types, attachments (Q4).
- Extension transport: which endpoints, headers and auth the transport must use.
- Project listing and pagination for bulk export (Q3).
- Branch monitor recognition of "Branch in new chat" (Q1, Q2).

## Decisions taken in this step

- `Node.createdAt` is optional (plan had it required): when a provider gives no time, Echoes leaves it out rather than
  inventing one. Plan update proposed.
- Bot-check detection: `cf-mitigated: challenge` header, or a 403 with an HTML body. Both pause; neither is retried
  automatically.
- A pause re-runs the request that hit it after `resume()`; it does not count as a retry.
- Package license is `UNLICENSED` until the v1-gate decision (MIT proposed).
